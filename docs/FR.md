### Categorized Requirements

#### 1. Trip Management
* **FR001 (Create Trip)**: The system shall allow user to create a new trip by entering trip name, destination and travel date.[cite: 14]
* **FR002 (Delete Trip)**: The system shall allow user to remove existing trip.[cite: 14]
* **FR003 (Edit Trip)**: The system shall allow user to modify the trip information after creation.[cite: 14]

#### 2. Itinerary Management
* **FR004 (Create Itinerary)**: The system shall allow user to create an itinerary.[cite: 14]
* **FR005 (Delete Itinerary)**: The system shall allow user to delete an itinerary.[cite: 14]
* **FR006 (Edit Itinerary)**: The system shall allow user to modify an itinerary detail.[cite: 14]

#### 3. Itinerary Items
* **FR007 (Add Itinerary Item)**: The system shall allow user to add new items into itinerary.[cite: 14]
* **FR008 (Delete Itinerary Item)**: The system shall allow user to remove itinerary items.[cite: 14]
* **FR009 (Edit Itinerary Item)**: The system shall allow user to modify itinerary details.[cite: 14]

#### 4. Travel Notes
* **FR010 (Add Travel Notes)**: The system shall allow user to create notes for trips and itinerary items.[cite: 14]
* **FR011 (Delete Travel Notes)**: The system shall allow user to delete notes for trips and itinerary items.[cite: 14]
* **FR012 (Edit Travel Notes)**: The system shall allow user to edit notes for trips and itinerary items.[cite: 14]

#### 5. Validation & Scheduling
* **FR013 (Detect Conflict Schedule)**: The system shall warns users when itinerary items overlap in time.[cite: 14]
