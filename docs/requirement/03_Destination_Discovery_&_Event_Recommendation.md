# 模块 03：目的地与活动 (Destination Discovery & Event Recommendation)

## 1. 地点搜索与地图交互 (Location Search & Map Interaction)
- **搜索与筛选**：支持输入关键词搜索地点，并按地点类型（如景点、餐厅等）进行条件筛选。
- **地图动态控制**：支持拖拽平移、滚轮及UI按钮（+/-）缩放，地图视口与图块实时平滑渲染。
- **联动定位**：搜索确认或点击地点 Pin 标注时，地图自动平移并居中至目标位置。

## 2. 地点详情查看 (Location Detail View)
- 点击地图上的地点标注可打开侧边栏，集中展示该地点的完整详细信息；支持随时关闭侧边栏返回地图主视图。

## 3. 节日与活动智能推荐 (Holiday & Event Recommendations)
- 根据旅行者的出行时间自动检索并生成推荐的**节日（Holiday）与活动（Event）**列表。
- 支持按类型筛选推荐结果，查看活动详情，并在地图上一键快速定位举办场地。

## 4. 收藏夹管理 (Favorites Management - CRUD)
- 融合地点的**收藏、收藏夹保存、查看与移除**功能：支持将地点保存至自定义收藏文件夹、浏览已收藏地点列表及移除不适用的收藏。
