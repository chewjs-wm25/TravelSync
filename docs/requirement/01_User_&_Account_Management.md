# 模块 01：用户与账户 (User & Account Management)

## 1. 身份验证与登录管理 (User Authentication & Login)
- 支持注册用户通过邮箱与密码登录，登录前自动校验邮箱格式与必填项。
- 校验用户邮箱验证状态、账号激活状态及锁定状态，验证通过后密码比对数据库哈希值。
- 支持"记住我"功能（保持登录状态最高7天）以及安全退出登录（销毁当前 Session）。

## 2. 账号安全防护与风控 (Account Security & Protection)
- **防暴力破解与限流**：单 IP 登录请求限流（最高 10 次/分钟）；连续 5 次登录失败自动锁定账号。
- **传输安全**：全站密码采用 HTTPS 加密传输。
- **异常提示**：对各种登录失败原因（如凭证无效、账号锁定、未验证等）提供精准错误提示。

## 3. 会话与状态管理 (Session Management)
- 登录成功后自动生成 Session Token 并重定向至个人仪表盘。
- 包含无操作超时机制：连续 30 分钟无活动自动过期 Session。

## 4. 账号注册与密码找回 (Registration & Account Recovery)
- 登录页面提供"注册"入口引导新用户创建账号。
- 提供"忘记密码"重置链接，支持用户进行密码重置。

## 5. 安全审计与日志记录 (Audit Logging & Tracking)
- 实时记录所有登录尝试（成功与失败）的时间戳及 IP 地址。
- 登录成功后自动更新用户的"最后登录时间"记录。
