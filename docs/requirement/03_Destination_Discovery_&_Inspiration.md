# 模块 03：目的地探索与灵感推荐 (Destination Discovery & Inspiration)

## 1. 智能地点搜索与多维筛选 (Smart POI Search & Filtering)
- **多维度条件筛选**：支持输入关键词搜索，并提供按体验类型、官方品质认证（如旅游质量评级）、文化及特定需求（如穆斯林友好设施）等多维度进行精确筛选。支持输入框自动联想（Geoapify autocomplete，服务端强制限定马来西亚）。
- **室内外场景分类**：提供按室内场馆或室外场景划分的专属标签，方便用户根据出行偏好寻找合适的场所。
- **州/省信息提供**：向行程规划（模块 02）输出马来西亚 13 州 + 3 联邦直辖区信息（`StateInfo`：标识 / 显示名 / 首府坐标 / 封面图），供创建旅行时选择州/省。

## 2. 灵感集锦与节日活动推荐 (Themed Collections & Event Discovery)
- **主题合辑推荐**：系统自动将优质地点打包为具有行动指导意义的灵感合辑（如"历史街区漫步指南"、"本地美食推荐"），激发用户出行灵感。合辑主题由 Wikivoyage 马来西亚分类树自动发现（区域 / 州分类 + 行程专题），支持"Generate more"分批加载。
- **节日与赛事联动**：展示马来西亚官方节日、文化活动与赛事的活动流（数据经官方活动同步至 D1），支持按分类标签与举办地点浏览。

## 3. 深度地点决策卡片 (POI Decision View)
- **全面详情展示**：提供详尽的地点信息，包含建议停留时长、最佳游玩时段、门票信息及当前营业状态提醒。
- **官方品质徽章**：在地点卡片上展示官方机构授予的评级认证徽章（白金、金、银级），帮助用户快速识别高质量旅游产品，降低决策成本。Recommended Places 官方品质评级独立展示（与搜索栏解绑，数据来自 D1 同步的官方评级）。
- **设施排雷提示**：直观展示无障碍设施配置等基础设施状态，确保各类人群的出行便利，避免实际出行时遭遇不便。
- **统一地点图片链路**：所有地点图片走统一的 Wikimedia（Wikivoyage → Wikipedia → Commons Geosearch）→ Mapillary 查询链，带开源协议署名展示（作者 + 许可声明）与多级缓存（内存 / sessionStorage / Cloudflare KV），降低免费 API 额度消耗。

## 4. 收藏管理 (Favorites Management)
- **自定义收藏管理**：支持将心仪的地点保存至收藏夹（每个用户一个收藏夹），支持按体验类型筛选收藏、移除收藏与跳转地点详情。
- **加入行程联动**：支持将收藏地点一键加入行程（模块 02，经跨模块桥接调用真实导入接口），实现"发现 → 收藏 → 规划"闭环。
