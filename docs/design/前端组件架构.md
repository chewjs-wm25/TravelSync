# 前端组件架构

> ⚠️ 待规划 — 本文档用于描述 TravelSync 前端的页面路由、组件树与状态管理。

## 规划要点（建议涵盖）
- **路由设计**：Next.js App Router 页面结构
- **页面清单（按模块）**
  - 模块01：登录页、注册页、仪表盘
  - 模块02：行程列表页、行程详情页（含时间线）
  - 模块03：地图探索页、地点详情侧边栏、收藏夹管理页
  - 模块04：路线规划页、路线优化页
  - 模块05：协作管理面板、群聊界面、投票/记账组件
- **共享组件库**：通用 UI 组件（地图、表单、卡片、弹窗等）
- **状态管理方案**：全局状态 / 服务端状态 / 本地状态的分离策略
- **与后端交互模式**：数据获取、缓存、乐观更新
