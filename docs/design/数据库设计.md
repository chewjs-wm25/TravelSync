# 数据库设计

> ⚠️ 待规划 — 本文档用于定义 TravelSync 各模块的数据模型。

## 规划要点（建议涵盖）
- **ER 图**：各模块的实体关系图（建议使用 PlantUML / Mermaid 表述）
- **表结构定义**：字段名、类型、约束、索引
- **核心表清单（按模块）**
  - 模块01：用户表、账户状态表、登录审计表
  - 模块02：行程表、行程明细表、类型分类表
  - 模块03：收藏夹表、收藏项表
  - 模块04：路线表、路线停靠点表
  - 模块05：协作成员表、角色权限表、版本记录表、投票表、费用分摊表、消息表、任务表
- **索引策略**：高频查询字段的索引规划
- **数据迁移策略**：版本迁移 / seeding 方案
