# API 接口设计

> ⚠️ 待规划 — 本文档用于定义 TravelSync 的前后端 / 服务间接口规范。

## 规划要点（建议涵盖）
- **接口风格**：RESTful / GraphQL / tRPC 选型说明
- **接口命名规范**：URL 路径、HTTP 方法、请求/响应格式
- **核心端点清单（按模块）**
  - 模块01：认证（登录/注册/登出/密码重置）、用户信息 CRUD
  - 模块02：行程 CRUD、行程明细 CRUD、排序与时间计算
  - 模块03：地点搜索、详情查询、收藏 CRUD、活动推荐
  - 模块04：路线生成、路线优化、路线 CRUD
  - 模块05：协作邀请、权限管理、实时同步、版本管理、投票/记账/消息
- **通用规范**：认证方式（JWT/Session）、分页、错误码、限流策略
