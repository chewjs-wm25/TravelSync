# 安全架构

> ⚠️ 待规划 — 本文档用于定义 TravelSync 的认证、授权与数据保护策略。

## 规划要点（建议涵盖）
- **认证流程**：注册验证 → 登录认证 → Session/JWT 管理 → 登出
- **授权模型**：RBAC 实现方案（Owner / Editor / Viewer 角色定义与权限矩阵）
- **数据保护**
  - 传输安全：HTTPS / HSTS
  - 存储安全：密码哈希（bcrypt/argon2）、敏感字段加密
- **风控策略**
  - 登录限流（IP 级别）
  - 账号锁定策略（连续失败次数）
- **安全审计**：日志记录规范、敏感操作追踪
- **API 安全**：CSRF 防护、XSS 防护、CORS 配置
