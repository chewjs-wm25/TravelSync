# TravelSync — 文档索引

## 文件夹用途

| 文件夹 | 用途 |
| :--- | :--- |
| `requirement/` | 各模块的功能需求，按模块拆分 (`<编号>_<模块名>.md`) |
| `use_case/` | 各模块的 Use Case 及描述，按模块拆分 (`<编号>_<模块名>.md`) |
| `design/` | 系统蓝图：架构、数据库、API、组件、安全等设计文档 |
| `backlog/` | 功能开发优先级与 Sprint 计划（待填充） |

## 文档关系链

`requirement`（做什么）→ `use_case`（怎么交互）→ `design`（怎么实现）→ `backlog`（先做什么）
