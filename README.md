## 本地开发

1. `npm install`
2. `npm run dev` （会自动执行 `npm run db:init` 初始化本地 D1 数据库：建表 + seed 数据）

> 新电脑第一次运行会自动建表 + 写入 seed（schema.sql，幂等可重复执行）。若需手动重置数据库，先删除 `.wrangler/state` 再重新 `npm run dev`。
